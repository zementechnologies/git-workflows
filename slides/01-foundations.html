ENGINEERING PLAYBOOK 01 / 07 // MODEL

Mental Models: Deltas vs Snapshots

The Delta Illusion

Treating Git as a cloud storage service that tracks line-by-line differences between files.

When merge conflicts or detached HEAD states occur, engineers panic and re-clone because the model fails them.

The Actual Architecture

Git is a content-addressable key-value datastore storing immutable snapshots in a Directed Acyclic Graph (DAG).

Every commit points to a root tree and its parents. Cryptographic hashes guarantee tamper-proof history.

ENGINEERING PLAYBOOK 02 / 07 // TREES

The Three Trees of Git

Where changes reside during active development:

1. Working Tree

The visible directory structure on your filesystem that you edit with your IDE.

Files on local disk

2. Staging Area (Index)

A binary file (.git/index) containing the proposed snapshot for the next commit.

git add file.ts

3. Git Repository

The permanent historical database stored under .git/objects/.

git commit -m "..."
ENGINEERING PLAYBOOK 03 / 07 // OBJECTS

Object Primitives in .git/objects/

  • Blob: Raw compressed file contents without metadata or filename.
  • Tree: Directory structure mapping filenames to blob or child tree hashes.
  • Commit: Snapshot record pointing to top tree, parent commit(s), author, and message.
  • Annotated Tag: Explicit reference pointer for release versioning.
# Inspect object type and contents
$ git cat-file -t HEAD
commit

$ git cat-file -p HEAD
tree 4b825dc642cb6eb9a060e54bf8d69288fbee4904
parent a1b2c3d4e5f67890123456789...
author Dev <dev@zemen.com.et> 1731400000 +0300
committer Dev <dev@zemen.com.et> 1731400000 +0300

feat(auth): add JWT bearer validation
ENGINEERING PLAYBOOK 04 / 07 // POINTERS

Branches: 41-Byte Reference Files

A branch in Git is not a container or duplicate folder. It is simply a text file containing a 40-character commit hash.

Implication: Branch creation, switching, and deletion are O(1) instantaneous operations. 
# View branch reference file directly
$ cat .git/refs/heads/main
a1b2c3d4e5f67890123456789abcdef012345678

# HEAD identifies the currently active ref:
$ cat .git/HEAD
ref: refs/heads/main
ENGINEERING PLAYBOOK 05 / 07 // COMMANDS

Standard Operations

# Check workspace status cleanly
git status -s

# Stage hunks interactively (atomic commits)
git add -p src/components/Navbar.tsx

# Create a conventional commit
git commit -m "feat(nav): add mobile navigation toggle"

# Switch to a new feature branch
git switch -c feat/billing-portal

# Compact graph visualization
git log --oneline --graph --decorate -n 10
