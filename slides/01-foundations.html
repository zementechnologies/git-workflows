ZEMEN TECHNOLOGIES 01 / 07 • CORE PHILOSOPHY

Why Git Confuses People

The Wrong Mental Model

Treating Git as a delta-based cloud backup system (like Google Drive or Dropbox).

"I pushed some file differences, Git calculates line changes, and if something goes wrong I re-clone."

The Real Mental Model

Git is a Content-Addressable Database storing immutable file snapshots connected as a Directed Acyclic Graph (DAG).

Every commit points to a root tree and its parent commits. SHA-1 hashes guarantee tamper-proof integrity.

ZEMEN TECHNOLOGIES 02 / 07 • THE THREE TREES

The Three Trees of Git

Understanding where your code lives at any second:

1. Working Directory

The visible files on your filesystem that you edit in VSCode / IDE. Untracked and uncommitted changes live here.

Real files on disk

2. Staging Area (Index)

A binary file (.git/index) holding the exact snapshot destined for your next commit. You curate this with git add.

git add file.ts

3. Git Repository

The permanent historical database inside .git/objects. Once committed, data is virtually impossible to lose.

git commit -m "..."
ZEMEN TECHNOLOGIES 03 / 07 • INTERNALS

Under The Hood: Git Objects

Inside the .git/objects/ directory, Git stores 4 primitive object types:

  • Blob: Raw file contents (compressed). Filename & permissions are not stored here.
  • Tree: Directory listing. Points to Blobs (files) and other Trees (subdirectories).
  • Commit: Snapshot metadata: pointer to top-level Tree, parent commit(s), author, timestamp, commit message.
  • Annotated Tag: Pointer to a specific commit with a cryptographic signature or release note.
# Inspect object type & content
$ git cat-file -t HEAD
commit

$ git cat-file -p HEAD
tree 4b825dc642cb6eb9a060e54bf8d69288fbee4904
parent a1b2c3d4e5f6...
author Aaron Kebede <aaron@zemen.com.et> 1731400000 +0300
committer Aaron Kebede <aaron@zemen.com.et> 1731400000 +0300

feat(auth): add JWT bearer validation
ZEMEN TECHNOLOGIES 04 / 07 • BRANCHES & HEAD

Branches & HEAD: 41-Byte Pointers

In Git, a branch is not a separate folder or container of files.

A branch is simply a text file containing a 40-character commit hash!

Key takeaway: Creating, switching, or deleting a branch in Git is practically instantaneous (O(1) complexity). 
# Look at the actual branch file:
$ cat .git/refs/heads/main
a1b2c3d4e5f67890123456789abcdef012345678

# HEAD tells Git what you currently have checked out:
$ cat .git/HEAD
ref: refs/heads/main
ZEMEN TECHNOLOGIES 05 / 07 • ESSENTIAL WORKFLOW

Daily Commands at Zemen

# Check repository state cleanly
git status -s

# Stage hunks interactively (commit atomic pieces!)
git add -p src/components/Navbar.tsx

# Create a clean conventional commit
git commit -m "feat(nav): add mobile responsive drawer toggle"

# Create and switch to a new feature branch
git switch -c feat/billing-portal

# View rich visual log
git log --oneline --graph --decorate --all -n 10
ZEMEN TECHNOLOGIES 06 / 07 • SETUP

Setting Up Your Zemen Identity

Ensure your company commits attribute properly to your Zemen profile:

# Global developer setup
git config --global user.name "Your Full Name"
git config --global user.email "yourname@zemen.com.et"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"

# Useful daily shortcuts
git config --global alias.st "status -sb"
git config --global alias.lg "log --oneline --graph --decorate -n 15"
git config --global alias.co checkout
git config --global alias.br branch
