ENGINEERING PLAYBOOK 01 / 05 // AI HYGIENE

Coding with AI Without Polluting History

The AI Anti-Pattern

Prompting an AI to generate changes across 30 files and immediately running git add . && git commit -m "AI changes".

Results in untraceable defects, hidden dead code, and unreviewable pull requests.

The Zemen Protocol

  1. Scoped Prompts: Prompt AI on single functions, modules, or tests.
  2. Diff Verification: Run git diff to inspect every proposed line.
  3. Atomic Staging: Stage hunks with git add -p with descriptive commit messages.
ENGINEERING PLAYBOOK 02 / 05 // AUTOMATION

Pre-commit Quality Automation

Intercept formatting issues and secret leaks before commits occur:

# Initialize client hooks
npx husky init
echo "npx lint-staged" > .husky/pre-commit

package.json Configuration:

{
  "lint-staged": {
    "*.{ts,tsx,js}": ["eslint --fix", "prettier --write"],
    "*.{json,md,css}": ["prettier --write"]
  }
}
ENGINEERING PLAYBOOK 03 / 05 // CI GATES

Automated PR Verification

Every pull request against main must satisfy status gates:

name: CI Quality Gate
on:
  pull_request:
    branches: [main]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - run: npm ci
      - run: npm run lint
      - run: npm run typecheck
      - run: npm test -- --coverage
