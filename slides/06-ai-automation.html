ZEMEN TECHNOLOGIES 01 / 06 • AI HYGIENE

Coding with AI Without Polluting Git

The AI Pitfall

Letting an AI agent edit 30 files across your workspace and running git add . && git commit -m "ai changes".

Results in untraceable bugs, commented-out dead code, and unreviewable 1,500-line pull requests.

The Zemen AI Workflow

  1. Scope Prompts: Ask AI to address one specific module or test at a time.
  2. Diff Verification: Run git diff to scrutinize every change.
  3. Atomic Staging: Stage with git add -p to verify each hunk before committing.
ZEMEN TECHNOLOGIES 02 / 06 • AUTOMATION

Pre-commit Automation: Husky & Lint-staged

Catch formatting errors, TypeScript build issues, and secrets BEFORE committing:

# Initialize Husky
npx husky init

# Add lint-staged check on pre-commit
echo "npx lint-staged" > .husky/pre-commit

package.json Configuration:

{
  "lint-staged": {
    "*.{ts,tsx,js,jsx}": ["eslint --fix", "prettier --write"],
    "*.{json,md,css}": ["prettier --write"]
  }
}
ZEMEN TECHNOLOGIES 03 / 06 • CI/CD

Automated PR Verification Pipeline

Every PR opened against main must pass automated status checks:

name: CI Quality Gate
on:
  pull_request:
    branches: [main]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - run: npm ci
      - run: npm run lint
      - run: npm run typecheck
      - run: npm test -- --coverage
ZEMEN TECHNOLOGIES 04 / 06 • TEAM PRODUCTIVITY

Bots That Keep Teams Fast

Auto-Assigner & Labeler

Automatically tags PRs based on touched directories (e.g. area: frontend, area: api) and assigns reviewers.

Conventional PR Linter

Ensures PR titles conform to feat:, fix:, chore: for automated release note generation.

Code Coverage Gate

Blocks merging if test coverage drops below team thresholds (e.g., > 80%).
