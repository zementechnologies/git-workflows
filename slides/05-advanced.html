ZEMEN TECHNOLOGIES 01 / 06 • REBASING

Interactive Rebase: Curating History

Before submitting a PR, polish messy WIP commits into a cohesive story:

# Rebase the last 4 commits
git rebase -i HEAD~4
  • pick : Keep the commit as-is
  • reword : Edit the commit message
  • edit : Pause and edit files before committing
  • squash : Meld into previous commit & combine messages
  • fixup : Meld into previous commit & discard message
  • drop : Remove the commit completely
The Golden Rule of Rebase:
Never rebase commits that have already been pushed to a public/shared branch (like main)! Only rebase your local private branch.
ZEMEN TECHNOLOGIES 02 / 06 • DISASTER RECOVERY

git reflog: Nothing Is Ever Lost

Accidentally ran git reset --hard or deleted a branch? Don't panic.

git reflog records every single movement of HEAD in your local repository for 30–90 days!

Even orphaned commits remain in the object store until garbage collection (git gc). 
# 1. View reflog history
$ git reflog
8f2d91a HEAD@{0}: reset: moving to HEAD~2
a34c192 HEAD@{1}: commit: add payment logic
b891e45 HEAD@{2}: checkout: moving from feat to main

# 2. Resurrect the "lost" commit!
$ git checkout -b recovered-work a34c192
Switched to a new branch 'recovered-work'
ZEMEN TECHNOLOGIES 03 / 06 • DEBUGGING

git bisect: Binary Search Your History

A production bug appeared somewhere in the last 200 commits? Don't guess—automate:

# 1. Start bisect mode
git bisect start

# 2. Mark current broken state
git bisect bad

# 3. Mark last known good commit/tag
git bisect good v1.8.0

# 4. Git checks out midpoint commit automatically.
# Test it, then inform Git:
git bisect good   # or: git bisect bad

# 5. Git zeroes in on the exact commit that broke production!
# When done:
git bisect reset
ZEMEN TECHNOLOGIES 04 / 06 • UNDO STRATEGIES

Reset vs Revert: Which to Use?

git reset (Rewrites History)

Moves the branch pointer backward. Erases commits from history.

  • --soft: Keeps changes staged in Index
  • --mixed: Keeps changes unstaged in Working Dir
  • --hard: Discards all changes

ONLY on private unpushed branches!

git revert (Forward Undo)

Creates an entirely new commit that inverts the changes of a previous commit. 

git revert a34c192

Safe for shared branches (main, staging)
