ENGINEERING PLAYBOOK 01 / 05 // REBASE

Interactive Rebase: Curating History

Clean up local WIP commits prior to opening a Pull Request:

# Rebase the last 4 commits
git rebase -i HEAD~4
  • pick Keep commit as-is
  • reword Modify commit message
  • edit Pause to amend staged files
  • squash Meld into prior commit and combine messages
  • fixup Meld into prior commit and discard message
  • drop Remove commit entirely
Safety Rule: Never rebase commits that have been pushed to shared branches (main, staging).
ENGINEERING PLAYBOOK 02 / 05 // REFLOG

git reflog: The Safety Net

Accidentally executed a hard reset? The Reference Log tracks every movement of HEAD locally for 30 to 90 days.

Even unreferenced commits remain on disk until garbage collection. 

# 1. View recent HEAD movements
$ git reflog
8f2d91a HEAD@{0}: reset: moving to HEAD~2
a34c192 HEAD@{1}: commit: add payment logic
b891e45 HEAD@{2}: checkout: moving from feat to main

# 2. Resurrect the orphaned commit:
$ git checkout -b recovered-branch a34c192
ENGINEERING PLAYBOOK 03 / 05 // UNDO

Reset vs Revert

git reset (Rewrites History)

Moves branch pointer backward. Erases commits from active history.

  • --soft: Keeps changes staged in Index
  • --mixed: Keeps changes unstaged in Working Tree
  • --hard: Discards all uncommitted changes

Only on local, private branches!

git revert (Forward Undo)

Creates a new commit that applies the exact inverse diff of an earlier commit. 

git revert <commit-hash>

Safe for shared branches (main, staging)
