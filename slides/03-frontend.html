ZEMEN TECHNOLOGIES 01 / 06 • LOCKFILES

Resolving Package Lockfile Conflicts

NEVER resolve package-lock.json or pnpm-lock.yaml manually in your code editor! Manual editing leads to corrupted dependency integrity hashes.

The 3-Step npm Solution:

# 1. Accept target package.json
git checkout --theirs package.json

# 2. Tell npm to regenerate the lockfile
npm install

# 3. Stage the clean regenerated lockfile
git add package.json package-lock.json
git commit -m "chore: regenerate package-lock"

For pnpm / yarn users:

# For pnpm:
pnpm install --fix-lockfile

# For yarn:
yarn install --check-files
ZEMEN TECHNOLOGIES 02 / 06 • PREVIEWS

Preview Environments per PR

Every active Pull Request should spin up an ephemeral preview URL so QA, designers, and product managers can test without running code locally.

  • GitHub Pages / Vercel Bot: Automatically comments on the PR with preview link.
  • Lighthouse CI Bot: Runs performance & accessibility scores against the branch.
  • Visual Regression: Captures screenshots to spot accidental CSS breaks.

Automated PR Bot Flow

Branch pushed → GitHub Actions runs build & tests → Preview deployed → Bot leaves comment:

[Status: Ready] Preview: https://zemen-app-feat-auth.vercel.app
[Performance] Lighthouse Score: 98 / 100

ZEMEN TECHNOLOGIES 04 / 06 • ASSETS

Handling Heavy Media Assets

Do NOT commit directly:

  • Raw 4K video files or uncompressed MP4s
  • Multi-megabyte Photoshop (.psd) or Figma files
  • High-res unoptimized PNGs or TIFFs

Bloats repository clone size for every team member forever!

Recommended Zemen Approaches:

  • Host marketing media on Cloudflare R2 / AWS S3 / Cloudinary CDN.
  • For in-repo assets, use Git LFS (Large File Storage):
git lfs install
git lfs track "*.psd" "*.mp4"
