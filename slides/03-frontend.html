ENGINEERING PLAYBOOK 01 / 05 // LOCKFILES

Resolving Package Lockfile Conflicts

Mandate: Never resolve package-lock.json or pnpm-lock.yaml manually in your code editor. Manual edits corrupt dependency integrity hashes.

The 3-Step Protocol (npm):

# 1. Accept target package.json
git checkout --theirs package.json

# 2. Reconstruct the dependency tree
npm install

# 3. Stage the verified lockfile
git add package.json package-lock.json
git commit -m "chore(deps): regenerate lockfile"

For pnpm & yarn:

# For pnpm:
pnpm install --fix-lockfile

# For yarn:
yarn install --check-files
