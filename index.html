Rapid Reference

Emergency Runbook & Cheatsheet

Instant solutions to the most common Git emergencies faced by engineers. Click copy to grab the command.

Typo in Last Commit Message

Fix the commit message before pushing:
git commit --amend -m "feat: corrected message"

Committed to Wrong Branch

Move the latest unpushed commit to a new branch:
git branch feat/my-feature && git reset --hard HEAD~1

Lost Commits with Hard Reset

Find your lost commit hash in reflog and restore:
git reflog && git checkout -b recover-branch HEAD@{1}

Lockfile Merge Conflict

Accept incoming package.json and regenerate cleanly:
git checkout --theirs package.json && npm install

Undo a Pushed Commit Safely

Revert without rewriting history on shared branch:
git revert <commit-hash> && git push origin main

Squash Last 3 Commits

Clean up messy WIP commits interactively:
git rebase -i HEAD~3
Background & Acknowledgements

Inspired by Flatiron Institute Sciware

This curriculum is directly modeled after the acclaimed Sciware initiative developed by the Flatiron Institute in New York City. Sciware established a remarkable open-source learning community focused on practical scientific software development and engineering workflows.

At Zemen Technologies PLC, we adapted this model for modern enterprise software development in Africa. We created targeted engineering tracks that bridge real-world business realities—such as distributed teams, payment gateway integrations, preview deployments, lockfile collisions, and AI agent coding—with foundational computer science and version control rigor.
